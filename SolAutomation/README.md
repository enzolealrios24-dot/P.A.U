# Sol Automation

Branch de build isolado para o mod de My Dystopian Robot Girlfriend.

## Funções
- Streaming automático ativável em Options via Mod Settings Menu.
- Avanço acelerado durante cena sexual de streaming.
- Para antes de fome/energia ultrapassarem o limite de segurança de 10%.
- Para quando o recurso de ejaculação do protagonista fica insuficiente.
- Auto pesca ativável apenas no minigame.
- Botão na tela e tecla P.
- Mantém a barra sobre o peixe por detecção dinâmica.
- Maximiza o progresso da captura e tenta continuar pescando com os próprios controles do jogo.

## Compatibilidade alvo
- MDRG 0.97.x, com foco no 0.97.12 enviado pelo usuário.
- MelonLoader 0.7.3.
- Mod Settings Menu 1.1.1.

O código usa reflexão para reduzir dependência de nomes internos entre pequenas atualizações do jogo.
