# Sol Automation 0.3.0

Mod para My Dystopian Robot Girlfriend 0.97.x.

- Streaming automático ativável em Options > Mod Settings Menu.
- Limite de segurança de 10% para fome/energia.
- Auto pesca ativável apenas no minigame.
- Botão na tela e tecla P.
- Implementação reflection-only para reduzir dependência dos assemblies internos entre versões 0.97.x.

Build automatizado via GitHub Actions.
